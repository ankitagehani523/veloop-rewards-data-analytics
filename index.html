VELOOP Rewards

Data Analyst Internship – Task 01

Product Analytics, Data Readiness & Data Management Blueprint

Project In Progress

Project Overview

This project aims to study the VELOOP Rewards platform and prepare a structured analytics blueprint. It focuses on product research, data requirements, event tracking, data quality, KPIs and dashboard planning.

About VELOOP Rewards

VELOOP Rewards is an online rewards platform that promotes earning opportunities through activities such as watching advertisements, completing tasks, playing games and referring friends.

Visit the official VELOOP website

Project Objectives

  • Understand the platform's product features.
  • Identify the data required for user activities.
  • Define analytics events and important KPIs.
  • Evaluate data quality using the provided simulated dataset.
  • Propose useful analytics dashboards and reporting structures.

Research Areas

  • User Registration and Login
  • Watch Ads and Task Completion
  • Daily Rewards and Bonus Income
  • Games, Missions and Referrals
  • Wallet and Withdrawals
  • Reward Transactions and Engagement

Deliverables Being Prepared

  • Product Data Readiness Audit
  • Data Coverage Matrix
  • User and Reward Analytics Specifications
  • Event Tracking Plan and Data Dictionary
  • Logical Data Model and KPI Catalogue
  • Simulated Data Profiling and Data Quality Audit
  • Dashboard Blueprint and Data Pipeline Proposal
  • Final Consolidated Report
