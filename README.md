# VELOOP Rewards – Data Analyst Internship Task 01

## 1. Project Overview

**Project Title:** VELOOP Rewards – Product Analytics, Data Readiness & Data Management Blueprint

**Project Type:** Data Analytics / Product Development

**Objective:**

The objective of this project is to understand the VELOOP Rewards platform and prepare a structured analytics blueprint. The project focuses on identifying product features, defining required data, planning event tracking, establishing KPIs, evaluating data quality and proposing useful analytics dashboards.

## 2. What is VELOOP Rewards?

VELOOP Rewards is an online rewards platform that promotes earning opportunities through activities such as watching advertisements, completing tasks, playing games and referring friends.

The platform also describes reward and wallet-related features.

This project will study the product using publicly available information and the simulated dataset provided for the internship assignment.

## 3. Project Scope

The project covers:

- Product and feature research
- Product Data Readiness Audit
- Data Coverage Matrix
- User Analytics Specification
- Earning, Reward and Wallet Analytics
- Referral and Engagement Analytics
- Event Tracking Plan
- Data Dictionary
- Logical Data Model
- KPI Catalogue
- Simulated Data Profiling
- Data Quality Audit
- Dashboard Blueprint
- Developer Analytics Handoff
- Data Pipeline Proposal
- Privacy and Data Governance
- Analytics Readiness Assessment
- Assumption and Verification Register
- Implementation Backlog
- Final Consolidated Report

## 4. Deliverables Being Prepared

The project will include Excel workbooks, documentation, data specifications, diagrams, dashboard designs and a final consolidated report, following the internship task PDF.
